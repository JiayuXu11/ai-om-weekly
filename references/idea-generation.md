# 研究选题筛选

本栏是本期信息上的推演，不是新闻事实。0–3个，宁可为空。目标刊会仅表示拟研究路径，不能承诺论文级别或发表。

每个候选写清：
1. 本期哪两项变化共同产生了尚未解决的问题，引用evidence_ids和可点击原文。
2. 研究问题、决策者、决策变量、信息结构和绩效目标；理论方向提出最小模型，AI方向提出任务、方法和关键对照。
3. 最相近已有工作的重叠与拟区别。必须进行针对性的查新检索；只检索摘要时注明，不得断言首创。
4. 一个可被证伪的机制猜想，明确尚未证明。
5. 最低验证：理论证明/反例或数据、基线、预算一致的实验和失败标准。

筛除：仅在现成模型中换成LLM；没有决策机制的泛泛应用；已有本期论文直接覆盖；从企业自述直接推出因果收益；堆砌名词而没有可验证问题。

建议每题4–6个短段落。新颖性存疑时说明具体重叠；若没有可信的区别则不输出。MS/OR/MSOM重视决策机制与可推广结论；AI顶会方向重视清楚的任务缺口、算法贡献及有说服力的实证。
